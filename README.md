# SISUM-TU: Campus Mail Management System
**Label: ETS & EAS Web Development BDI**

SISUM-TU is a full-stack web application designed to digitize and streamline administrative correspondence within university departments. This system manages the complete lifecycle of incoming and outgoing mail.

## 🚀 Key Features
- **Dashboard Analytics:** Real-time monitoring of pending and completed mail.
- **Mail Workflow:** Automated status tracking for outgoing mail.
- **Leadership Module:** Dedicated interface for document approval and signatures (TTD).
- **Notification Center:** Centralized alerts for new mail and urgent actions.
- **Role-Based Access:** Secure login for Staff TU and Pimpinan.

## 🛠️ Tech Stack
- **Backend:** PHP (Native)
- **Database:** MySQL
- **Frontend:** Tailwind CSS & FontAwesome Icons
- **Version Control:** Git

## 📂 Project Structure
Classified by importance and functionality:
- `auth/`: User authentication and session management.
- `config/`: Database connection and core configurations.
- `modules/`: Functional modules (Surat Masuk, Surat Keluar, Akun).
- `assets/`: Styling and UI resources.
